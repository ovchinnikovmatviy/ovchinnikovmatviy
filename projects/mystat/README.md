# MyStat · Student portal concept

## About the project

MyStat is an independent redesign concept for the IT STEP student portal, created together by **Matvii Ovchinnikov and Nikita Popruga (Amnex)**. We explored how to make everyday student tasks easier to find and use across desktop and mobile screens.

The demo presents the proposed interface and a comparison with the existing portal. It uses fictional data and has no live backend or connection to student accounts.

### What you can explore

- A customizable dashboard with widgets that can be reordered, hidden and restored.
- Assignments and learning materials, with deadlines, statuses and task details.
- Schedule and calendar, grades and attendance views.
- Rewards, rankings and a demonstration store.
- Settings and a help center.
- Ukrainian, Russian and English interfaces.
- Light, dark and automatic appearance, with responsive desktop and mobile layouts.

Purchases, document downloads and other actions are demonstrations, not real transactions or official services.

### Technologies

**HTML · CSS · JavaScript**

A static frontend with interface translations stored in JSON files, shared styling tokens and browser local storage for interface preferences. The public demo is hosted on Cloudflare Pages.

### Authors and status

This is a collaborative portfolio project by Matvii Ovchinnikov and Nikita Popruga, not commercial employment or an official IT STEP product.

IT STEP positively received our work and told us they plan to implement the concept. Actual deployment within IT STEP has not yet been confirmed.

The source repository is private. This page provides a public overview; the interactive demo is accessible without repository access.

## О проекте

Мы с **Никитой Попругой (Amnex)** сделали независимый концепт обновления студенческого кабинета IT STEP. Авторы: **Матвій Овчінніков и Никита Попруга**.

**[Посмотреть демо](https://mystat-concept.pages.dev/)**

В демо можно посмотреть новый интерфейс и сравнение с текущим порталом. Данные вымышленные, подключения к студенческим аккаунтам и рабочего backend нет.

### Что есть в концепте

- Главная с плитками, которые можно перемещать, скрывать и возвращать.
- Задания и материалы: сроки, статусы и подробности работы.
- Расписание, календарь, оценки и посещаемость.
- Награды, рейтинг и демонстрационный магазин.
- Настройки и центр помощи.
- Украинский, русский и английский языки.
- Светлая, тёмная и автоматическая темы, адаптация под компьютер и телефон.

Покупки, скачивание справок и другие подобные действия показаны как симуляция.

### Технологии и статус

HTML, CSS и JavaScript. Переводы хранятся в JSON, настройки интерфейса сохраняются в браузере. Демо размещено на Cloudflare Pages.

IT STEP понравилась работа, и они сообщили, что планируют внедрить концепт. Фактическое внедрение пока не подтверждено. Это совместный проект для портфолио, не коммерческая работа и не официальный продукт Академии.
